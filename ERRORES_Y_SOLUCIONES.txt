Carrito.jsx — lee carrito[] del contexto y muestra los items con el total calculado.

FormularioContainer.jsx (alta.jsx) — maneja el estado del formulario y hace POST a MockAPI. Su hijo FormularioProducto es puramente presentacional.

ChatIA.jsx — chat con IA. Hace POST a http://localhost:3001/chat (el servidor Express). Detecta intención de compra y muestra un formulario de contacto.

server.js — servidor Express independiente (puerto 3001). Recibe mensajes del chat y los reenvía a OpenRouter (Llama 3).

ProductoDetalle.jsx — lee el id de la URL con useParams(). Por ahora solo muestra el ID, no carga datos del producto.

Comunicación entre componentes
Contexto (CartContext): ItemListConteinerNew escribe via agregarAlCarrito. Carrito lee via carrito[]. Comunicación sin prop drilling.
Props hacia abajo: ItemListConteinerNew → Item (datos del producto + callback onCompra). FormularioContainer → FormularioProducto (datos del form + handlers).

React Router: App define las rutas, Layout usa <Outlet> para renderizar la ruta activa. Navbar navega con <Link>.
Fetch externo: cargaProductos → MockAPI / JSON local. ChatIA → localhost:3001. alta.jsx → MockAPI (POST).

import { createContext, useState } from "react";

export const CartContext = createContext();

export function CartProvider({ children }) {
  const [carrito, setCarrito] = useState([]);

  const agregarAlCarrito = (producto, cantidad) => {
    setCarrito((prev) => {
      const existe = prev.find((item) => item.id === producto.id);

      if (existe) {
        return prev.map((item) =>
          item.id === producto.id
            ? {
                ...item,
                cantidad: item.cantidad + cantidad,
              }
            : item
        );
      }

      return [
        ...prev,
        {
          ...producto,
          cantidad,
        },
      ];
    });
  };

  return (
    <CartContext.Provider
      value={{
        carrito,
        agregarAlCarrito,
      }}
    >
      {children}
    </CartContext.Provider>
  );
}
